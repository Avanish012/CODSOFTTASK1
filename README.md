## Task 1: Data Cleaning and Preprocessing

### Objective
To import a dataset using Python, inspect its structure, identify missing values,
duplicate records and inconsistent entries, clean the data using Pandas,
and save the cleaned dataset as a new CSV file.

### Tools Used
- Python
- Pandas
- COLOB
- GitHub

### Work Performed
- Imported the dataset using Pandas.
- Inspected the dataset structure.
- Identified missing values and inconsistent entries.
- Converted columns to appropriate data types.
- Handled missing values.
- Removed duplicate records.
- Recalculated Total Spent.
- Exported the cleaned dataset as a new CSV file.

### Files
- Original dataset
- Python cleaning script
- Cleaned dataset
- Task report
